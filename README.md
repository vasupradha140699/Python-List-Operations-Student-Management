# Python-List-Operations-Student-Management
A Python project demonstrating list operations through a student management example, including adding, removing, searching, sorting, copying, indexing, slicing, and clearing student records
## Description
This project demonstrates Python list manipulation using a student list. It covers common list methods and operations for managing student names.

## Features
- Add students using `append()`, `insert()`, and `extend()`
- Remove students using `remove()`, `pop()`, and `clear()`
- Search and count names using `index()` and `count()`
- Sort and reverse student names
- Copy lists and find list length
- Check membership using `in` and `not in`
- Perform indexing and slicing

## Technologies
Python, Lists, Built-in List Methods

## Objective
To understand and practice Python list operations through a simple student management example.
